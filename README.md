## O que estou construindo aqui

Os projetos neste perfil refletem minha trajetória em dados aplicados a negócios:

- **Análise comercial** — estudos de comportamento de clientes, segmentação e tendências de vendas
- **Dashboards e KPIs** — modelos e visualizações para acompanhamento de receita, margem e performance
- **Queries e modelagem** — scripts SQL otimizados e estruturas de dados para relatórios gerenciais
- **Automação de relatórios** — pipelines em Python para reduzir trabalho manual e aumentar confiabilidade

> A maioria dos projetos usa dados públicos ou sintéticos, mas seguem a mesma lógica dos problemas reais que resolvo no dia a dia.
